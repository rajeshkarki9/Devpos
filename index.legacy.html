01 Setup

git config --global user.name "Your Name"

Set the name attached to your commits.

git config --global user.email "you@example.com"

Set the email address used for your commits.

git config --global init.defaultBranch main

Use main as the default name for new branches.

git clone https://github.com/user/repo.git

Copy a GitHub repository onto your computer.

02 Everyday basics

git init

Start tracking a project in the current folder.

git status

See what's changed and what is ready to commit.

git add filename

Stage one file for your next commit.

git add .

Stage all changed files in this folder.

git commit -m "describe your change"

Save staged changes as a new snapshot.

03 Branches

git branch

List local branches; the current one has an asterisk.

git switch -c feature/my-change

Create a branch and switch to it.

git switch main

Move to an existing branch.

git merge feature/my-change

Bring another branch's changes into the current branch.

git branch -d feature/my-change

Delete a branch that has already been merged.

04 Sync with GitHub

git remote add origin https://github.com/user/repo.git

Connect your local project to a GitHub repository.

git remote -v

Check which remote repositories are connected.

git fetch

Download updates from GitHub without merging them.

git pull

Fetch and merge changes from the current branch's remote.

git push -u origin main

Publish a branch and set its upstream on GitHub.

05 Undo & fix

git restore filename

Discard unstaged changes in a file. This cannot be undone.

git restore --staged filename

Unstage a file while keeping your changes.

git revert commit-id

Undo a commit by creating a new, safe-to-share commit.

git reset --soft HEAD~1

Undo your last commit but keep its changes staged.

git commit --amend -m "new message"

Update the last commit message. Avoid amending commits already shared.

06 Look around

git log --oneline

Scan a compact list of recent commits.

git diff

Review changes that have not been staged yet.

git diff --staged

Review exactly what will go into your next commit.

git show commit-id

Inspect a commit and the changes it introduced.

git blame filename

See who last changed each line in a file.

07 Stash & tags

git stash

Tuck away uncommitted changes so you can switch tasks.

git stash pop

Bring back your most recently stashed changes.

git stash list

See all of your saved stashes.

git tag v1.0.0

Mark a commit with a release version.

git push origin --tags

Publish your local tags to GitHub.
